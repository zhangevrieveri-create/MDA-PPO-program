# MDA-PPO：多模态数据驱动的深度强化学习投资模型

论文《基于深度强化学习的多模态数据驱动智能投资模型》的代码实现。

## MDA-PPO 算法

MDA-PPO 把每日的选股与资金配置看作一个马尔可夫决策过程，用 PPO-Clip 训练。每个交易日收盘时，模型读取股票池中
全部股票过去 T 个交易日的量价与舆情特征，对每只股票打分，取得分最高的 10 只股票，与现金（国债逆回购）一起归一化
得到当日的组合权重。

奖励函数由三部分组成：

    R_t = 0.4·R_short + 0.5·DSR + 0.1·Penalty

- R_short：扣除交易成本后的持仓收益，交易成本按调仓换手量计提，双边 0.15%
- DSR：差分夏普比率（Moody 和 Saffell，2001）
- Penalty = −(2x_t − 1)²，x_t 为当日股票总仓位，避免过度空仓或满仓

训练过程：

1. 采样时在策略标准差上加入课程噪声 σ_noise,k = σ0·exp(−βk)，测试时直接取均值 μ；
2. 缓存区存满 C=1000 步连续轨迹后，用 GAE 计算优势函数，分 E=10 轮、每轮按 B=100 的小批量更新策略网络和价值网络，
   更新后清空缓存区；
3. 裁剪参数随市场波动率调整，ε_t = ε0(1 + 0.5σ_t/σ̄_W)；学习率每 100 步按 η = η0·exp(−αΔL/L) 调整。

主要超参数：η0=3×10⁻⁴，γ=0.99，GAE 参数 0.95，ε0=0.2，σ0=0.4，β=0.004，无风险利率 1%。

## 模型结构

```
输入 S_t（U 只股票 × T 个交易日 × 25 个特征）
  → BatchNorm
  → Bi-LSTM（1 层，隐藏层 128，双向拼接为 256 维）
  → Transformer 编码器（2 层，8 头，前馈层 128，GELU）
  → 时间注意力（每只股票沿时间维度）+ 标的注意力（每个交易日沿股票维度），拼接为 512 维
  → 沿时间平均得到每只股票的特征 h_t,i，再对全部股票平均得到 H_global

策略网络：h_t,i → 512→128 → 每只股票得分的均值与标准差（各股票共用同一组输出层参数）
          H_global → 512→128 → 现金头寸的均值与标准差
价值网络：H_global → 512→128→1
```

输出层由各股票共享，模型参数量与股票数量无关，共 1,477,253 个。

输入特征共 25 维：

- 量价 22 维：开盘价、收盘价、最高价、最低价、成交量、换手率；MA5/10/30/120、EMA30、布林带上轨与下轨、ATR、ADX、
  KDJ（K、D、J）、RSI6/12/24、CCI
- 舆情 3 维：累积净情绪 CNS、累积情绪分歧度 CDIV、米筐个股新闻情绪（滞后 1 个交易日）

新闻标题用 FinBERT（finbert-tone-chinese）得到负向、中性、正向三类概率，按股票和交易日聚合为净情绪与情绪分歧度，
再按衰减因子 λ 逐日累积。15:00 收盘后发布的新闻归入下一个交易日。

## 数据说明

论文的样本为 3699 只 A 股（剔除北交所、样本期内曾被 ST、样本期内退市以及上市不满一年的股票），样本期为
2014-01-06 至 2025-10-29，其中 2023-03-20 之前为训练集，之后为测试集。量价数据来自米筐 RQData，新闻标题来自
新浪财经和米筐个股新闻。

由于数据隐私与授权权限的限制，本仓库不上传原始量价与新闻数据，只能提供 2024 年 12 月 31 日之前的少量示例。
`examples/rq4/` 中给出贵州茅台、五粮液、招商银行、中国平安 4 只股票 2017—2024 年处理后的训练数据集 `rq4.npz`
（约 0.8 MB）及其训练、回测结果，可以直接跑通训练与回测。示例的股票少、训练轮数少，结果不代表论文的实证结论。
原始数据、全部股票或 2025 年以后的数据需要自行购买米筐 RQData 授权，账号写在本地的 `configs/local_rqdata.yaml`
中（该文件不会提交），再依次运行第 1~4 步构建数据集。

## 运行

```bash
pip install -r requirements.txt
python scripts/00_selftest.py      # 不需要数据，检查模型结构与训练流程
```

| 步骤 | 脚本 | 内容 |
|---|---|---|
| 1 | `01_fetch_market.py` | 米筐量价、基准指数、个股新闻 |
| 2 | `02_crawl_news.py` | 新浪财经新闻标题 |
| 3 | `03_build_sentiment.py` | 新闻情绪 |
| 4 | `04_build_dataset.py` | 构建训练数据集 |
| 5 | `05_train.py` | 训练 |
| 6 | `06_backtest.py` | 测试集回测 |
| 7 | `07_baselines.py` | 对比方法与夏普比率差异检验 |

每个脚本都可以用 `--config` 指定配置文件，全部参数在 `configs/default.yaml`。使用示例数据：

```bash
python scripts/05_train.py    --config examples/rq4/config.yaml --epochs 15
python scripts/06_backtest.py --config examples/rq4/config.yaml
```

消融实验通过配置切换：`rl.cash: false` 去掉无风险资产，`dataset.sentiment: []` 去掉舆情特征，
`rl.weighting: equal` 改为入选股票等权。
